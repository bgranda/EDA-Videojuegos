# EDA-Videojuegos
Es un proyecto de un Análisis Exploratorio de Datos (EDA) de las ventas de videojuegos en el mundo. El proyecto está realizado por Beatriz Granda Arroyo.

# Obtención de datos
La obtención de datos se ha realizado en la página de Kaggle, de la cual se han podido descargar todos los datasets de multiples fuentes.

# Hipótesis de los datos

Plataforma que más videojuegos vende.
Si la plataforma depende del género de videojuegos.
Si hay mayor número de ventas de videojuegos, en una región u otra.
